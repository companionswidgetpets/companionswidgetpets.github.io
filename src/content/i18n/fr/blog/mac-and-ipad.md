## Sur le Mac

Depuis macOS Sonoma, un Mac peut afficher les widgets d’un iPhone connecté au même compte Apple, à condition que les deux soient proches l’un de l’autre ou sur le même réseau Wi-Fi. Companions n’a pas besoin d’app Mac pour cela : les widgets de votre iPhone deviennent tout simplement disponibles sur le bureau.

<ol class="steps">
<li>Sur le Mac, ouvrez <strong>Réglages Système › Bureau et Dock</strong>, faites défiler jusqu’à <strong>Widgets</strong> et activez <strong>Utiliser des widgets pour iPhone</strong>.</li>
<li>Cliquez avec le bouton droit (ou en maintenant la touche Contrôle enfoncée) sur un espace vide du bureau et choisissez <strong>Modifier les widgets</strong>.</li>
<li>Dans la galerie, trouvez <strong>Companions</strong> ; les widgets pour iPhone sont signalés par un petit téléphone. Choisissez une taille et faites-la glisser sur le bureau, ou dans le Centre de notifications.</li>
<li>Cliquez sur <strong>Terminé</strong>.</li>
</ol>

Le Mac affiche le widget tel que votre iPhone le dessine : un poisson ajouté sur le téléphone apparaît donc aussi sur le Mac. Un clic sur le widget, côté Mac, vous renvoie vers l’iPhone grâce à Continuité, au lieu d’ouvrir l’app.

### Les poissons sur le Mac : à quoi s’attendre

Sur l’écran d’accueil de l’iPhone, les poissons nagent en continu, car c’est iOS lui-même qui anime le widget. Sur le Mac, les widgets pour iPhone sont des images reproduites depuis le téléphone, et c’est macOS qui décide à quelle fréquence il en demande une nouvelle. Sur votre bureau, les poissons peuvent donc avancer par à-coups au lieu de nager en douceur : c’est le cas de tous les widgets pour iPhone sur le Mac, et l’app n’y peut rien.

### Les widgets du bureau vous gênent ?

**Réglages Système › Bureau et Dock › Widgets** propose des options pour afficher les widgets sur le bureau, dans Stage Manager, et pour les estomper quand une app est au premier plan.

## Sur l’iPad

Companions est une app iPad native, avec les trois mêmes tailles de widget, pour iPadOS 26 ou version ultérieure. Les aquariums y sont disposés comme sur l’iPhone : un aquarium composé sur l’un a le même aspect sur l’autre. Le widget s’ajoute à l’écran d’accueil de l’iPad de la même façon : maintenez le doigt sur l’écran d’accueil, touchez **Modifier**, puis **Ajouter un widget**.

Les packs et l’offre Tous les poissons suivent votre compte Apple : tout ce que vous avez acheté sur l’iPhone vous appartient aussi sur l’iPad, et si un pack apparaît verrouillé, touchez **Restaurer l’achat** dans les Réglages de l’app. Les aquariums et les poissons, eux, restent sur chaque appareil : pour transférer la composition d’un aquarium, utilisez **Partager cet aquarium** sur l’un et ouvrez le code sur l’autre.
