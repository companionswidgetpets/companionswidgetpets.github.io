---
question: "Comment renommer ou retirer un poisson ?"
summary: "Touchez le poisson dans le plateau sous l’aquarium : vous pouvez alors changer son nom ou le retirer. Retirer un poisson le supprime de votre appareil ; rien d’autre ne change dans l’aquarium."
---
Le plateau sous l’aquarium affiche les poissons qu’il contient, avec leur nom. Touchez-en un :

- **Renommer** : changez le nom et touchez OK. Vous pouvez choisir n’importe quel nom : votre meilleur ami, une star de la K-pop, toute la bande d’une sitcom. Il s’affiche dans le plateau et quand VoiceOver lit le widget ; rien n’est écrit sur le poisson lui-même.
- **Retirer** : le poisson se dissout dans l’eau et sa case se libère pour un autre. Retirer un poisson le supprime de votre appareil.

Chaque poisson porte d’abord le nom de son espèce : le poisson-clown s’appelle « Clown » jusqu’à ce que vous en décidiez autrement. Deux poissons de la même espèce peuvent avoir des noms différents : c’est ainsi que l’app les distingue.

Les noms restent sur votre appareil. Companions ne crée aucun compte et n’envoie jamais votre aquarium en ligne ; voir la [politique de confidentialité](/fr/privacy/).
