---
question: "Peut-on partager son aquarium avec un ami ?"
summary: "Oui. « Partager cet aquarium », dans le menu ⋯, crée un code et une image de l’aquarium. L’ami qui ouvre le code dans Companions retrouve votre eau, vos décorations et votre complication sur son étagère, avec ses propres poissons dedans."
---
Touchez **⋯** en haut de la page principale et choisissez **Partager cet aquarium**. Companions prépare deux choses et ouvre la feuille de partage :

- Une **image** de l’aquarium, présentée comme une carte avec le nom de l’app, prête à partir dans Messages ou en story.
- Un **code** qui contient la composition de l’aquarium : son style, chaque décoration et sa place, et sa complication s’il en a une.

Envoyez l’un ou l’autre. Toute personne qui a Companions et ouvre le code retrouve votre aquarium sur son étagère de cette taille, exactement tel que vous l’avez disposé, avec ses propres poissons dedans. Le code ne contient rien sur vous ni sur vos poissons : les noms et les poissons ne quittent jamais votre appareil. Voir la [politique de confidentialité](/fr/privacy/).

Si l’aquarium a une complication (l’heure, la date, la météo, les pas ou la Lune), la personne qui le reçoit a besoin de l’offre Tous les poissons pour la garder ; sinon, elle reçoit l’aquarium sans rien dans le coin, et un message le lui signale.

Vous pouvez aussi enregistrer le code QR comme image dans Photos ; la première fois, iOS vous demande l’autorisation de l’ajouter.
