summary: "아니요. 위젯은 자체 코드를 실행하지 않습니다. 앱이 넘겨준 설명대로 iOS가 물고기를 그리며, 시계 위젯의 바늘을 돌리는 것과 같은 방식입니다. 백그라운드에서 돌아가는 것은 없습니다."

다른 위젯보다 더 많이 쓰지는 않습니다. 홈 화면 위젯은 화면에 떠 있는 동안 코드를 실행할 수 없고, Companions도 그러려 하지 않습니다. 앱은 어항을 설명하는 정보를 iOS에 넘겨줍니다. 여기에는 물고기마다 헤엄치는 경로를 만드는 작은 ‘시곗바늘’ 몇 개가 들어 있고, iOS는 시계 위젯의 초침을 돌릴 때와 같은 방식으로 어항을 그립니다. 홈 화면 뒤에서 돌아가는 Companions의 프로세스도, 앱을 깨우는 타이머도, 네트워크 연결도 없습니다.

앱 자체도 열려 있을 때만 일합니다. 물고기를 추가하거나 이름을 바꾸거나 제거할 때, 어항의 스타일이나 장식을 바꿀 때, 설정을 조정할 때 어항을 저장하고 iOS에 위젯을 한 번 다시 그려 달라고 요청할 뿐입니다.

무언가를 가져오는 컴플리케이션은 두 가지입니다. **날씨**는 하루 세 번 Apple의 날씨 서비스에 예보를 요청하고, **걸음 목표**는 건강 앱에서 오늘의 걸음 수를 읽어 옵니다. 둘 다 잠깐이면 끝나고, 직접 선택했을 때만 켜집니다.

움직이는 콘텐츠가 다 그렇듯, 위젯도 화면에 보이는 동안에는 화면을 다시 그리도록 요청합니다. 시계 화면을 띄워 두는 것과 같은 정도입니다. 상시표시형 디스플레이가 있는 iPhone에서 밤새 스탠바이를 쓴다면, iOS가 다른 모든 위젯과 마찬가지로 화면을 어둡게 하고 갱신 속도를 낮춥니다.
