Getting started

Add an aquarium widget to your iPhone Home Screen

How to put the Companions fish tank on your Home Screen in iOS 26, choose between the small, medium and large widget, and keep a different tank in each size.

By Tiaan van der Riel · November 9, 2026 · Companions 4.5

On this page

  1. Before you start
  2. Add the widget
  3. Choosing a size
  4. A different tank in each size
  5. If it doesn’t appear
  6. Good to know

Companions is a widget first. The app is where you choose fish and arrange tanks; the Home Screen is where you see them. This guide takes you from a fresh install to a tank that swims beside your other apps.

Before you start

Open Companions once. A fresh install starts with a small blue Minimal tank and three fish, the Tang, the Sardine and the Puffer, so there is already something for the widget to show. If you’d like to add or rename a fish first, tap the + at the end of the tray under the tank; you can always come back to it.

Add the widget

  1. Touch and hold an empty part of your Home Screen until the icons start to jiggle.
  2. Tap Edit in the top-left corner, then Add Widget.
  3. Search for Companions, or scroll down to it.
  4. Swipe sideways between the three sizes and tap Add Widget under the one you want.
  5. Drag it where you'd like it, then tap Done.

The widget shows exactly what the app shows for that size, including the glass highlight iOS puts over every widget; the app draws its tank through the same glass so the two match.

Choosing a size

  • Small is a square the size of four icons. It is also the size StandBy and the Apple Watch use.
  • Medium is the width of the screen and two icons tall: a wide tank, good for schools of small fish.
  • Large is the width of the screen and four icons tall, with room for the whales and a shelf of props.

In the app, swipe the main page sideways to see each size as it will look. You can add several widgets, in the same size or different ones.

A different tank in each size

Each widget size is its own tank, with its own five fish, its own style, props and complication. Swipe to the medium tank in the app and the tray shows the medium tank’s fish, which start empty; add whatever suits a wide tank. The My Tanks page (in the ⋯ menu) keeps a shelf of designs per size, and the Explore page has eighteen ready-made tanks, six per size, to start from.

If it doesn’t appear

Open the app once; that asks iOS to redraw the widgets. If the widget is blank or stale after that, touch and hold it, choose Remove Widget and add it again, or restart your iPhone. More in the widget isn’t updating.

Good to know

  • A Companions widget can live in a Smart Stack with other widgets. iOS then rotates the stack through the day, so the tank isn’t always on top; keep it out of a stack if you want the fish in view all the time.
  • The widget reads the tank from storage it shares with the app and runs no code of its own, so it costs no more battery than a clock widget. See does Companions drain my battery?
